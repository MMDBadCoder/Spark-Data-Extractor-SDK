# Repository setup

Canonical repository: `MMDBadCoder/Spark-Data-Extractor-SDK`

URL: <https://github.com/MMDBadCoder/Spark-Data-Extractor-SDK>

Title: Spark Connect Data Extractor

Description: Python SDK for bounded HDFS Parquet extraction with Spark Connect, Persian notebook guidance, verified gzip CSV manifests, and a WebHDFS download CLI.

Visibility: public.

## Local workspace

This hosted workspace keeps Git metadata in `.repo-metadata`, with this directory
configured as its work tree. Run Git here as:

```bash
git --git-dir=.repo-metadata status
```

This is a workspace constraint, not a requirement of the SDK. A normal clone uses
standard Git commands:

```bash
git clone https://github.com/MMDBadCoder/Spark-Data-Extractor-SDK.git
cd Spark-Data-Extractor-SDK
```
